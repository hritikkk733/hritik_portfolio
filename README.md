# Hritik Kumar - Full Stack Developer Portfolio

A modern, high-performance developer portfolio built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

![Portfolio Screenshot](https://raw.githubusercontent.com/hritikkk733/hritik_portfolio/main/public/favicon.svg)

## 🚀 Features

- **Interactive Developer Terminal**: Embedded interactive CLI (`cat bio.json`, `hritik.skills()`, `hritik.projects()`, `hritik.contact()`, `clear`) with clickable command pills and instant responses.
- **Dynamic Typewriter Hero**: Rotating specialty titles with ambient gradient glow.
- **Projects Showcase & Architecture Modal**: Detailed project cards with category filters (`All`, `Full-Stack`, `AI & Cloud`, `Enterprise & Banking`), live links, GitHub links, and comprehensive system architecture breakdowns.
- **Skills Matrix**: Categorized technical skills across Frontend, Backend, Databases, and AI/Tools with progress levels and highlight badges.
- **Work Experience & Education**: Real-world experience at Sanjivani Media & Technologies and academic distinction background (B.Sc. in Physics from Patliputra University).
- **Printable Resume Modal**: In-browser resume viewer with one-click print/PDF download and copy-to-clipboard functionality.
- **Interactive Contact Hub**: Direct contact form with subject selectors, celebratory confetti, copy-to-clipboard for Email & Phone with toast notifications, and WhatsApp direct link.
- **Dual Theme Support**: Seamless Dark Mode and Light Mode with persistent `localStorage` preference.
- **Ultra Fast Performance**: Sub-250ms production builds powered by Vite & Tailwind CSS v4.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)

- **Celebration Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Deployment**: Ready for [Vercel](https://vercel.com/) or [GitHub Pages](https://pages.github.com/)

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/hritikkk733/hritik_portfolio.git
cd hritik_portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

---

## 📦 Production Build

```bash
# Type-check and build for production
npm run build

# Preview production build locally
npm run preview
```
